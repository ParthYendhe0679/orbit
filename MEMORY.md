# Orbit Trading AI — Context Ledger & Architecture Log

## Tech Stack
- **Backend**: FastAPI, WebSockets, Python 3.13, SQLite / Neon PostgreSQL
- **Frontend**: Vanilla JavaScript (ES6+), Three.js (WebGL 3D Scene), Lightweight Charts / TradingView Widget, CSS3 (Modern Glassmorphism & Monochrome Dark Theme)
- **AI Engine**: 12 Quantitative Agents (Chart, Indicator, News, Momentum Candle, EMA Ribbon, Volatility, Volume Flow, MTF Trend, Strategy Judge, Risk Planner, Execution, Portfolio Monitor)

## Design System & User Preferences
- **Theme**: Ultra-minimalist Black & White / Deep Monochrome theme (`#000000` / `#06070a` base, `#ffffff` headers, silver secondary, `#00ff88` emerald for bullish/buy, `#ff3366` ruby for bearish/sell).
- **Layout**: High-impact Split-Screen Hero inspired by modern fintech/Dribbble/Three.js landing pages. Left side: clean, punchy hero typography, pill CTA, live status. Right side: dynamic 3D isometric laptop with live financial candlestick screen, 3D BUY/SELL capsule keys, ascending green area profit chart, soaring pink arrow, gold coin, magnifying glass, and surrounding flock of moving 3D candlesticks.
- **Streamlined Structure**: Direct 2-stage flow consisting of the 3D Hero Landing Page and the glassmorphic Terminal Login portal immediately below upon scrolling. Extra card grids (skills suite, 12 strategies, agents grid, architecture) removed per user request for pure minimalism.
- **Rules**: Zero silent deletions of existing functionality or agents. Strict minimalism.
